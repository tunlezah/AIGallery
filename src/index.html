Help: getting into the gallery

Add or edit a curated item

Curated items live in the content repository, not in this site’s repo. Each top-level directory is a section; a directory one level below it becomes a gallery item when it contains an index.md:

tooling/                  <- section
└─ my-tool/              <- item
   ├─ index.md           <- required
   └─ cover.png          <- optional image

index.md is YAML frontmatter plus a Markdown body shown on the card:

---
title: "My Tool"          # required
url: "https://example.com"
image: "cover.png"        # omit to use the gallery default image
tags: ["local", "cli"]
summary: "One line, up to 200 chars."
---
Free Markdown body.

To modify an existing item, edit its index.md (or replace its image) and open a merge request on the content repository. To remove one, delete its directory or set draft: true.

Host your own item via a GitLab topic

Any project on this GitLab instance can list itself — no merge request needed. Under your project’s Settings → General → Topics, add the topic {{TOPIC_NAME}}. The project’s name, description, avatar and other topics become the card, which appears in the gallery’s subscribed section on the next scheduled build. Projects without an avatar get the gallery default image.

For more control, commit a manifest at {{TOPIC_MANIFEST_PATH}} on your default branch, using the same frontmatter format as a curated item — its fields override the derived metadata, and its body becomes the card body. Remove the topic to leave the gallery.
